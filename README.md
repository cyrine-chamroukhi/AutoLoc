# AutoLoc

Application de location de véhicules développée avec Java, Spring Boot et Maven.

## Objectif

AutoLoc est une application permettant de gérer la location de véhicules ainsi que les différentes opérations associées.

## Acteurs

- Client
- Agent
- Manager
- Administrateur

## Technologies

- Java 17
- Spring Boot
- Maven
- MySQL
- Git / GitHub
- Postman
